四、登录注册业务设计

====================



支持两种注册模式，并以第一种作为默认实现：

​    自动创建账号；

​    保存用户协议确认记录；

​    然后登录。

\- 自动生成默认昵称，例如 用户_XXXXXX

\- password 可以为空

\- 后续可以进入「设置密码」

手机号

→ 自动登录

十三、JWT认证设计

====================



采用：



Access Token + Refresh Token



Access Token：

建议有效期约 2 小时。



Refresh Token：

建议有效期约 30 天。



Access Token：



JWT形式。



包含最少字段：



sub / userId

iat

exp

tokenType



避免把手机号、密码、隐私字段大量写入 JWT。



JWT Secret：



不得写死在 Git 仓库。



从：



application.yml 环境变量

或服务器环境变量



读取。



例如：



JWT_SECRET



Refresh Token：



建议使用不可预测的随机 Token。



数据库只保存：



tokenHash



不要直接保存 Refresh Token 明文。



退出登录时将 Refresh Token 撤销。
